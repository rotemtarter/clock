# שעון השמיים

שעון דיגיטלי לפי שעון ישראל, עם תמונת השמיים מעל תל אביב בזמן אמת.

- השמש והירח מוצגים במיקומם האמיתי בשמיים (גובה וכיוון), לפי חישוב אסטרונומי.
- הגודל של השמש והירח מחושב לפי המרחק שלהם באותו רגע. התמונה מוגדלת, אבל היחס ביניהם אמיתי.
- מופע הירח והצד המואר שלו מחושבים לפי מיקום השמש.
- צבע השמיים משתנה לפי השעה: יום, שקיעה, דמדומים ולילה עם כוכבים.
- קו הרקיע של תל אביב בתחתית הדף, עם חלונות מוארים בלילה.
- כרטיסי מידע: גובה, כיוון, גודל נראה, מופע הירח ושעות זריחה ושקיעה.
- כפתורים להרצת הזמן מהר (×120, ×1200).

## הרצה

זה קובץ HTML אחד בלי תלויות. אפשר לפתוח את `index.html` ישירות בדפדפן, או להריץ שרת מקומי:

```bash
python3 -m http.server 8080
```

ואז לגלוש אל http://localhost:8080
